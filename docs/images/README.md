# Screenshot sources

These images were captured from USCE at 1600 x 900 using its native screenshot
function. They show the Modern theme with the Blue skin.

- `singing.jpg`: three-player playback of the original demonstration song
  **Your stage**, with the lyric “Sing together, make this night ours”. Its
  melody, synthesized audio and lyric were created for these screenshots.
  No commercial song, recording, cover or music-video frame is included.
- `player-setup.jpg`: the 24-player setup screen with default player names.
- `release-2026.10-highlights.png`: annotated composition of the two captures.
  Screenshot inserts show the application; labels and leader lines are editorial.

The demonstration background is the existing USCE blue branding artwork.
Theme artwork and avatars retain the notices distributed with the game.
Capture build: main at 1dc43844 plus the preview-volume fix (38c4b0a4),
player-selection fixes (90d01ab3), compact Tools layout (b641d70f),
and visual scaling corrections (afa4e848).

The screenshot capture and original demo content were prepared with AI assistance;
the highlights composition uses an editable SVG with the original screenshot
inserts. No screenshot score was fabricated.
