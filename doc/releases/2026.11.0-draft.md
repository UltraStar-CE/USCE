# USCE 2026.11.0 (draft)

## Changes since USCE 2026.10.0

### Singing and audio

- Combined duet high scores, with separate and combined display modes. Existing On settings keep separate scores. [#67](https://github.com/UltraStar-CE/USCE/pull/67)
- Per-player timing delays, including scoring during pre-roll for negative delays, complete delayed notes at song end, and correct resets after seeking. [#43](https://github.com/UltraStar-CE/USCE/pull/43), [#132](https://github.com/UltraStar-CE/USCE/pull/132)
- Use PortAudio playback on macOS, with SDL fallback and safer stream shutdown. [#34](https://github.com/UltraStar-CE/USCE/pull/34)
- Correct controller keyboard simulation and modifier handling. [#35](https://github.com/UltraStar-CE/USCE/pull/35)

### Editor

- Alt+P playback combinations use the shared synth and click engine. Previews stop at EOF and their exact end time, and onward playback clears single-note state. [#116](https://github.com/UltraStar-CE/USCE/pull/116)
- Restore Ctrl/Shift pitch shortcuts for solo songs while keeping duet controls. [#121](https://github.com/UltraStar-CE/USCE/pull/121)
- Play synth-only note previews for their full duration and show their playback progress. [#122](https://github.com/UltraStar-CE/USCE/pull/122)

### Names, scores and languages

- Localize default Party player/team names while preserving custom names and shared name entry. [#125](https://github.com/UltraStar-CE/USCE/pull/125)
- Keep player and team name suggestion histories separate. [#129](https://github.com/UltraStar-CE/USCE/pull/129)
- Give high-score values and dates enough space without overlapping or truncating them. Keep statistics visible with older theme layouts. [#123](https://github.com/UltraStar-CE/USCE/pull/123)
- Add Esperanto, including the corrected audio-device wording. [#27](https://github.com/UltraStar-CE/USCE/pull/27)

### Build and maintenance

- Check installed English fallback files against matching game sources. [#126](https://github.com/UltraStar-CE/USCE/pull/126)
- Stabilize ARM macOS runner selection and report the actual failed platform. [#127](https://github.com/UltraStar-CE/USCE/pull/127)
- Handle asynchronous macOS disk-image detachment during packaging. [#128](https://github.com/UltraStar-CE/USCE/pull/128)
- Validate the immutable PR changes instead of waiting for unrelated workflows. [#130](https://github.com/UltraStar-CE/USCE/pull/130)
