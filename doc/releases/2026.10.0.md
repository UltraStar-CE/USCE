UltraStar Community Edition's first monthly release builds on UltraStar Deluxe 2026.10.0, with USCE branding and all themes bundled in every platform package.

## :rotating_light: Breaking changes

* Avatars, themes and plugins are detected in home and application directories. On Linux, highscore plugins are no longer loaded from the installation directory.

## :chart_with_upwards_trend: Enhancements

* All themes from the USCE Themes repository are included in the downloads.
* Duets save highscores. This can be disabled in Options > Advanced.

## :beetle: Bug Fixes

* Keep the version label short enough to fit themed screen footers.
* Fix crashes caused by an invalid song `#VERSION`.
* Fix selection colours for colourized textures.
* Fix fullscreen glitches.

## Other Changes

* Introduce USCE branding and a shorter, player-focused README.
* Integrate native Windows dependency builds into Autotools and correct runtime library packaging.
* Use MSYS2's patch tool when building Windows dependencies.
* Detect missing external library functions during macOS builds.
* Include upstream's macOS crash stacktraces, code signing, sdl2-compat support and temporary-file cleanup.
* Update Italian and Icelandic translations.
* Remove obsolete Lazarus project files.
* Document Lua 5.5 support.
* Use the USCE application bundle name on macOS.
* Preserve upstream compiler-flag fixes for Windows and Intel Macs.

Thanks to the UltraStar Deluxe contributors and everyone helping build USCE.
