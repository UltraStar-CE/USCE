UltraStar Community Edition's first monthly release includes the changes below **compared with USDX 2026.9.0**. It incorporates USDX 2026.10.0 and the USCE additions listed here. Future release notes will describe changes since the previous USCE release.

![New in USCE 2026.10: two-screen 24-player singing, editor score breakdown, synth timing and adaptable themes](https://raw.githubusercontent.com/UltraStar-CE/USCE/main/docs/images/release-2026.10-highlights.png)

This release adds 24-player layouts, editor score breakdowns, shared synth and
beat-click timing, and expanded playlist controls. Windows can be resized and
themes adapt to the screen aspect ratio, including 16:9 and 21:9.

## :rotating_light: Breaking changes

* Avatars, themes and plugins are detected in home and application directories. On Linux, highscore plugins are no longer loaded from the installation directory. [`365f9be`](https://github.com/UltraStar-CE/USCE/commit/365f9bedee6644510934300f9de349a604656c9f), [`167e14f`](https://github.com/UltraStar-CE/USCE/commit/167e14f3763985728a8969e56987c21a1d46c921)

* Remove the obsolete basic editor and MIDI-import screens. The full song editor remains available. [#68](https://github.com/UltraStar-CE/USCE/pull/68)
* Use the built-in synthesizer for all MIDI previews. System and external MIDI output through PortMidi are no longer available. [#78](https://github.com/UltraStar-CE/USCE/pull/78)
* Allow medleys for any song with playable notes, including duets and relative songs. Explicit medley ranges still take priority; the legacy `CALCMEDLEY=Off` switch no longer excludes a song. [#64](https://github.com/UltraStar-CE/USCE/pull/64)
* Remove rap and medley badges from song selection; video and duet indicators remain. [#65](https://github.com/UltraStar-CE/USCE/pull/65)

## :chart_with_upwards_trend: Enhancements

* Keep fonts, images and avatars in proportion across screen aspect ratios. [#83](https://github.com/UltraStar-CE/USCE/pull/83)
* Use generic player layouts across player selection, duet selection, singing and scoring, with selectable player counts up to 24. [#70](https://github.com/UltraStar-CE/USCE/pull/70), [#71](https://github.com/UltraStar-CE/USCE/pull/71), [#72](https://github.com/UltraStar-CE/USCE/pull/72), [#76](https://github.com/UltraStar-CE/USCE/pull/76), [#77](https://github.com/UltraStar-CE/USCE/pull/77)
* Accelerate note shifting while holding the editor keys. [#49](https://github.com/UltraStar-CE/USCE/pull/49)
* Improve built-in MIDI synthesis and unify editor beat and MIDI preview timing. [#78](https://github.com/UltraStar-CE/USCE/pull/78)
* Add a remaining-score bar showing the score still achievable, with rating-only, remaining-only and combined display modes. [#62](https://github.com/UltraStar-CE/USCE/pull/62)
* Add playlist search, sorting, reordering and controls for adding or removing the displayed songs. Refresh active playlists when their files change. [#61](https://github.com/UltraStar-CE/USCE/pull/61), [#46](https://github.com/UltraStar-CE/USCE/pull/46)
* Keep preview music running consistently across player selection and results, and toggle fullscreen video previews with V. [#55](https://github.com/UltraStar-CE/USCE/pull/55), [#29](https://github.com/UltraStar-CE/USCE/pull/29)
* Let K cycle through full vocals, a saved partial vocals volume and instrumental playback when a partial volume is configured. [#37](https://github.com/UltraStar-CE/USCE/pull/37)
* Show the perfect-score split between normal notes, golden notes and line bonuses in the editor, and add absolute pitch diagnostics in recording options. [#44](https://github.com/UltraStar-CE/USCE/pull/44), [#59](https://github.com/UltraStar-CE/USCE/pull/59)
* Search by several characters while holding Alt, with improved navigation out of song folders. [#40](https://github.com/UltraStar-CE/USCE/pull/40)
* Improve chained theme and skin inheritance, including shared assets, themed sounds and category covers. [#81](https://github.com/UltraStar-CE/USCE/pull/81), [#52](https://github.com/UltraStar-CE/USCE/pull/52), [#54](https://github.com/UltraStar-CE/USCE/pull/54)
* All themes from the USCE Themes repository are included in the downloads. [#20](https://github.com/UltraStar-CE/USCE/pull/20)
* Duets save highscores. This can be disabled in Options > Advanced. [`255e3bd`](https://github.com/UltraStar-CE/USCE/commit/255e3bdafa36d6e40f9c256eb22f509be21433db), [`6798291`](https://github.com/UltraStar-CE/USCE/commit/67982915bbae26222bd68933587c2c299a89d9f8)
