# Compiling
[Free Pascal](http://freepascal.org/) 3.0.0 or newer is required to compile UltraStar Community Edition. Using the newest version is suggested.
For linking and running the game, the following libraries are also required:
- SDL2, SDL2_image
- FFmpeg 4.0-9.0
- SQLite 3
- [BASS](http://www.un4seen.com/bass.html)
- some fonts like DejaVu
- PortAudio
- Lua 5.1, 5.2, 5.3, 5.4, or 5.5
- OpenCV if you want webcam support
- projectM 4,x if you want audio visualisation support

## Compiling using make
### Install prequisites
#### Linux/BSD
Required libraries:
- Debian/Ubuntu: `git automake make gcc fpc libsdl2-image-dev libavformat-dev libavcodec-dev libavutil-dev libswresample-dev libswscale-dev libsqlite3-dev libfreetype6-dev portaudio19-dev liblua5.3-dev libopencv-videoio-dev fonts-dejavu`
- Fedora: `git automake make gcc fpc SDL2_image-devel ffmpeg-devel sqlite-devel freetype-devel portaudio-devel lua-devel opencv-devel`
- Archlinux: see the dependencies in the [ultrastardx-git](https://aur.archlinux.org/packages/ultrastardx-git) AUR package

Optional libraries:
- [ProjectM](https://github.com/projectM-visualizer/projectm) visualization: You may need to compile this from source because 4.0 or later is required, but many distros still ship 2.x or 3.x
- Webcam: `g++ libopencv-dev` (Debian/Ubuntu)

#### MacOS (High Sierra and above)
- Install Homebrew. Follow instructions from [brew.sh](http://brew.sh)
- `brew install fpc` or get it from [freepascal.org](http://www.freepascal.org/down/i386/macosx.var)
- `xcode-select --install`
- `brew install sdl2 sdl2_image automake portaudio binutils sqlite freetype lua libtiff pkg-config ffmpeg opencv`

#### Windows using MSYS2
- Install [MSYS2](https://www.msys2.org). Use the UCRT64 environment
- Install [FPC](https://www.freepascal.org). Use the Win32 cross-to-Win64 installer so you get the Win64 RTL units.
- `pacman -S base-devel mingw-w64-ucrt-x86_64-toolchain mingw-w64-ucrt-x86_64-autotools mingw-w64-ucrt-x86_64-cmake mingw-w64-ucrt-x86_64-meson mingw-w64-ucrt-x86_64-ninja mingw-w64-ucrt-x86_64-git mingw-w64-ucrt-x86_64-ntldd mingw-w64-ucrt-x86_64-nasm mingw-w64-ucrt-x86_64-python patch unzip`
- Add some information to `.bash_profile`:
  * Path to the cross compiler: `PATH="${PATH}:/c/FPC/3.2.2/bin/i386-win32"`
  * FPC config and base: `FPCCFG="/c/FPC/3.2.2/bin/i386-win32/fpc.cfg"` and `FPCDIR="/c/FPC/3.2.2"`

Keep MSYS2's `/ucrt64/bin` and `/usr/bin` ahead of the FPC directory in `PATH`.
In particular, `command -v patch` should select `/usr/bin/patch`, not FPC's old
bundled patch tool. Install all prerequisites above before building dependencies.

### Compile and run
The Windows dependency build requires MSYS2's `/usr/bin/patch` (`pacman -S patch`)
and uses it explicitly, avoiding FPC's older bundled patch tool.

Version metadata is generated by autogen using Git and Python 3. For direct IDE
builds, run `python3 tools/generate-version.py` before compiling.

- `git clone https://github.com/UltraStar-CE/USCE`
- `cd USCE`
- Windows only: compile the DLLs with `make -C dists/windows install`
- `./autogen.sh`
- `./configure` (see optional flags below)
- `make` (on macOS: `make macos-standalone-app`)
- `./game/usce[.exe]` (on MacOS: `open "UltraStar Community Edition.app"`)

Modern is bundled, so a checkout runs without downloading themes. Themes is the
source of truth: the bundled `Modern.ini` and `Modern/` assets must match the
exact revision in `themes.json`. CI checks missing, extra and changed files.

After merging a Modern change in Themes, update the pin, fetch that exact
commit into `.release-themes/source`, then run
`python3 tools/bundle-themes.py sync-modern`. Commit the pin and synchronized
files together. The sync command refuses dirty Modern files and preserves
untracked custom assets. `check-modern` performs the same comparison without
writing. On Windows use `python` instead of `python3`.

Optional themes can be installed with `python3 tools/bundle-themes.py setup`.
Setup adds missing files from the pinned snapshot, preserves local additions,
and refuses conflicting existing files before copying anything. Release
packages include the complete pinned snapshot.

On Windows, `make` builds the game and its enabled wrappers; the separate
dependency step supplies the runtime DLLs. If launching reports a missing DLL,
check that `make -C dists/windows install` completed successfully, then rerun
`./configure` and `make` so configuration and binaries match those dependencies.

#### configure flags
* `--enable-debug`: Outputs warnings and errors from Error.log also to the console.
  Caught exceptions include their class, message and available stack trace in
  `Error.log` in both normal and debug builds. The report is flushed before the
  error dialog opens. Debug information makes stack addresses more useful.
* `--with-portaudio`: This is the default on Linux and macOS. Windows uses SDL audio input.
* `--without-portaudio`: Use SDL audio input instead.
  This should support newer platforms like PulseAudio and PipeWire.
  Might not be able to detect the number of channels correctly when used with PulseAudio.
  Might fix issues experienced when using PortAudio on certain distributions.
* `--with-opencv`: Enable webcam support with OpenCV. By default, configure
  auto-detects OpenCV 3+ and disables webcam support if OpenCV is not found.
* `--without-opencv`: Build without webcam support even if OpenCV is installed.

For local macOS builds, use `make macos-standalone-app MACOS_SIGN_IDENTITY="Your certificate name"`
or the same variable with `macos-dmg`. Both signing steps use that identity.
The default remains ad-hoc signing (`-`); CI needs no certificate. Selecting an
identity alone does not guarantee that macOS will retain microphone permission.

## Flatpak packaging

USCE does not yet have a published Flathub package. The upstream USDX manifest
at https://github.com/flathub/eu.usdx.UltraStarDeluxe is a reference only;
installing it installs USDX, not this edition. A USCE manifest must select the
USCE source commit, app ID `org.ultrastarce.usce`, executable `usce`, and the
matching reviewed dependencies before publication.

# Windows installer
The CI does this for you, but if you need to do it manually:
- Create Windows portable version: zip the contents of the `game` directory
- Create Windows installer:
  * Install NSIS (also install the Graphics and Language components during setup)
  * Copy the DLLs from `game` to `installer/dependencies/dll`
  * `C:\...\makensis "installer/UltraStar Community Edition.nsi"` (this will take a while)
  * The .exe will be placed in `installer/dist`

## Locked playlist playback

Create a playlist in song selection, using the playlist menu to add the current
selection if needed. Launch it with:

```
usce -lockdown -playlist "Karaoke" -password "pw" -results 10 -highscores 10
```

One playlist is accepted. Lockdown always enables continuous playback and repeat;
unlocking requires the password. The remaining singing configuration options are:

- `-results` and `-highscores`: `manual`, `skip`, `5`, `10`, `20`, `30`, `40`, `50`, `60` (seconds).
- `-song-display`: `lyrics-progress`, `lyrics`, `progress`, `none`.
- `-singing-display`: `full`, `notes-info`, `notes`, `info`, `none`.

Omitted options use the saved continuous-playback profile.

## Signed APT repository

Ubuntu packages are published by the separate [UltraStar-CE/apt repository](https://github.com/UltraStar-CE/apt).
See its README for supported distributions, installation and signing/publication setup.
The DEB packages themselves remain part of USCE releases.
