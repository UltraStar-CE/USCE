UltraStar Community Edition (USCE)

USCE is an independently maintained fork of UltraStar Deluxe (USDX),
which is based on UltraStar by corvus5.
USCE was introduced on 2026-10-16 and continues to incorporate relevant
upstream changes. The Git history records USCE-specific changes.

USCE contributors are credited in this repository's pull requests, Git
history, and individual file notices. The project maintainers are Daniel
Gruss and Tycho Schottdorf. See MAINTAINERS.md for current responsibilities.

Additional USCE contributors:
- Wiccio: Esperanto translations, Windows installer patch, and testing.
- Thallion: SDL microphone reconnect patch and hardware testing.

USCE contribution history: https://github.com/UltraStar-CE/USCE
